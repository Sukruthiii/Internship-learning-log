# Experiment 1 - Multi-Signal Generator

This experiment focuses on generating sine, square, and triangle waves using LabVIEW.

## Objective

To develop a LabVIEW application that generates three different waveforms: Sine, Square, and Triangle.

## Concepts Used

- For Loop
- Case Structure
- Enum and Cluster Type Definitions
- Unbundle By Name
- Auto-Indexing
- Build Waveform
- Waveform Graph
- Sampling Frequency and Sampling Interval
- DSP Signal Generation Concepts

## Project Structure

- **Main VI:** LabVIEW program for generating signals.
- **Controls:** Reusable Type Definition controls.
- **Documentation:** Detailed experiment explanation, formulas, and observations.
- **Screenshots:** Front Panel, Block Diagram, and generated waveform outputs.

## Result

The application is designed to generate and display sine, square, and triangle waveforms using configurable signal parameters.

## Learning Outcome

Gained practical experience in LabVIEW programming, waveform generation, data structures, loops, Case Structures, and basic Digital Signal Processing (DSP) concepts.
